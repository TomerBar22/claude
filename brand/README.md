# Golden Patio Restoration — brand assets

Source of truth: `Golden_Patio_Brand_Guidelines.pdf`. The PNGs here were extracted from it.

| File | Use |
|---|---|
| `logo-primary.png` | Primary vertical lockup, charcoal text, for light backgrounds |
| `logo-primary-reversed.png` | Primary lockup, ivory text, for dark backgrounds / photo overlays |
| `logo-compact-h-reversed.png` | Compact horizontal (no descriptor), ivory text, for corner bugs |
| `mark-gold.png` | Archway mark alone, gold gradient |
| `badge-gold.png` | Simplified favicon / app-icon badge |

## Palette
- Primary: Gold `#B18B2E`, Charcoal `#3D3527`
- Secondary: Light Gold `#D8B55B`, Teal `#6BC0C0`
- Neutrals: Ivory `#FAF7F5`, Warm Sand `#F5EDDC`, Mist `#E9EFED`, Taupe `#92897D`, Pale Teal `#ABD5D4`

Gold is the hero accent, not a wall-to-wall wash.

## Type
- Wordmark is custom artwork. Always use the logo files and never retype it.
- Descriptor/supporting text: Proxima Nova (licensed). Jost is the free stand-in.
- Headings in the guide: Playfair Display.

## Don'ts
Don't stretch, recolor, tilt, add shadows/glows, place on clashing backgrounds, or reduce the mark's opacity.
